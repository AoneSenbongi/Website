# Blog・日記の公開

本番接続後の管理画面は `https://yamachikaseiya.com/admin/`。管理者としてログインし、記事または日記を選ぶ。

1. 新規作成または一覧から既存の投稿を開く。
2. 内容を入力して「公開」を押す。未保存の変更も含めて公開される。
3. 公開後の編集も「公開」で更新する。「保存」は下書き保存で、公開中の投稿は確認後に非公開になる。

投稿ごとのCodexへの依頼、ZIP出力、Git操作は不要。公開操作そのものが投稿者の公開意思となる。

Markdown対応の公開候補では、本文に `## 小見出し`、`**太字**`、`- 箇条書き`、リンクやコードを書ける。HTMLタグは文字として表示する。表示は保存後のプレビューで確認できる。

## 初回接続の残作業

認証とサービス有効化は完了。D1・R2・Access・Turnstile、本番Pagesの秘密情報を設定済み。公開候補の承認待ち。

- 既存サイトと新しい管理画面を含む公開候補を提示し、今回の公開内容への確認を得る。
- 承認後に配信設定を反映し、本番で認証、公開、更新、下書きの非公開を確認する。

初回公開ではメール通知を無効にする。PagesにはCron Triggerがなく、メール送信元も未設定。期限切れ記録はアクセスを契機に削除する。以前のローカル執筆画面の下書きは自動移行しない。

## ローカル試験

通常の下書きを変更しない試験用サーバー:

```powershell
$env:BLOG_PREVIEW_PORT = '4198'
$env:BLOG_PREVIEW_ISOLATED = '1'
npm run dev
```

別のPowerShellで `npm run test:publish`。試験データは `.local/publish-check` に保存する。ここでの「公開」はPC内だけで、本番公開ではない。
