4D Viewer

4Dルービックキューブを観察・操作するためのビューアを制作中です。

4Dルービックキューブを3Dでどう見るか

このプロジェクトでは、4Dルービックキューブの状態を三次元の空間に表現し、観察・操作する方法を考えています。四次元の構造や回転をそのまま見ることはできないため、どの情報をどの位置・視点で見せれば理解しやすいかを試作しています。

基礎となる試作：3Dを2Dで見る

3D → 2D Viewer

4Dを3Dで表現する前段として、3Dの構造を2Dの画面上で理解するための試作をまとめています。 3D → 2D の試作を見る →
