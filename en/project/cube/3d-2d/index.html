4D Viewer / Foundation Studies

3D → 2D

As a foundation for representing a 4D Rubik’s Cube in 3D, these prototypes explore how to communicate 3D structure, viewpoint, and interaction on a 2D screen.

Projection

3D Cube → 2D Projection

A demo that keeps the cube’s 3D state while projecting it onto a 2D canvas, allowing the viewpoint and cube to be rotated.

Open demo ↗

Plane

3D → 2D Plane

A prototype for viewing a 3D cube as a 2D plane while switching which axis is omitted.

Open demo ↗

Net

Cube Net Viewer

A prototype that lays out every face as a cube net so the three-dimensional state can be inspected on a flat surface.
