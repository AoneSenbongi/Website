Projects
4D Cube

4次元立方体（テッセラクト）の可視化・投影に関するプロジェクトです。

4次元空間上の立方体を4次元座標として扱い、4次元空間内での回転や変換を行ったうえで、低次元空間へ投影する方法を研究・実装しています。

Webブラウザ上で4次元幾何をインタラクティブに可視化し、4次元空間の構造や投影による変化を確認できるようにすることを目的としています。

インタラクティブデモ：
https://yamachikaseiya.com/project/cube/3d-2d

Blog

Blogは日本語のみで公開します。公開サイトは静的な閲覧用ページで、投稿画面や記事の保存APIは含めません。

執筆はPC内のローカルツールで行います。下書きと写真は公開サイトから分離し、公開する記事だけを確認してサイトへ反映します。今回の公開にはサンプル記事や下書きを含めません。

Newsには主な更新の日付と内容を載せます。トップには直近3件を表示し、過去の更新は同じ場所で開ける形式にします。過去分の日付はGitの更新記録に基づき、学会の開催日や実際の公開日時とは区別します。

トップページは自己紹介、News、About Me、ResearchとBlogの順に表示します。Projectは従来どおりヘッダーから参照できます。
