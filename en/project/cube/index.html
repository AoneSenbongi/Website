In Progress / Interactive Viewer

4D Viewer

I am developing a viewer for exploring and manipulating a 4D Rubik’s Cube.

How can a 4D Rubik’s Cube be viewed in 3D?

This project explores ways to represent the state of a 4D Rubik’s Cube in three-dimensional space so that it can be observed and manipulated. Because four-dimensional structure and rotation cannot be viewed directly, I am prototyping which information, positions, and viewpoints make the structure easiest to understand.
