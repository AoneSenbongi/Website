Projects
4D Cube

4次元立方体（テッセラクト）の可視化・投影に関するプロジェクトです。

4次元空間上の立方体を4次元座標として扱い、4次元空間内での回転や変換を行ったうえで、低次元空間へ投影する方法を研究・実装しています。

Webブラウザ上で4次元幾何をインタラクティブに可視化し、4次元空間の構造や投影による変化を確認できるようにすることを目的としています。

インタラクティブデモ：
https://yamachikaseiya.com/project/cube/3d-2d

Blog

Blogと日記は日本語のみです。このブランチでは、Cloudflare Pages Functions・D1・R2を使う記事・日記の管理、匿名いいね、承認制コメント・返信、任意の返信通知、X共有を追加しています。管理画面と保存APIは管理者認証で保護し、下書きは公開しません。本人のコメントには認証に基づくバッジを付けます。

本番の保存先とCloudflare Accessを準備済みで、Pagesへの反映は公開候補の承認待ちです。初回公開ではメール通知を無効にします。仕様、認証、データの扱い、公開手順は `docs/BLOG_DYNAMIC.md` を参照してください。以前のローカル執筆データは自動移行していません。日記は新しい管理画面から日付ごとに投稿できます。

Newsには主な更新の日付と内容を載せます。トップには直近3件を表示し、過去の更新は同じ場所で開ける形式にします。過去分の日付はGitの更新記録に基づき、学会の開催日や実際の公開日時とは区別します。

トップページは自己紹介、News、About Me、ResearchとBlogの順に表示します。Projectは従来どおりヘッダーから参照できます。

Local Development

リポジトリをクローンしてください。

git clone https://github.com/AoneSenbongi/Website.git
cd Website

Blogの確認は `npm ci`、`npm run dev` の順に実行し、表示されたローカルURLを開いてください。メールは外部送信せず、ローカルの確認用受信箱へ保存します。既存の静的ページだけなら、静的Webサーバーでも表示できます。
